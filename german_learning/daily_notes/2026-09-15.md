## Imperative practice — 3/4 clean

1. "Gib mir das Buch." ✅ — asked why **mir** and not **mich**. Answered:
   geben has two objects (das Buch = accusative direct object, mir = dative
   indirect object/receiver) — same dative/accusative pattern as normal
   sentences ("Ich gebe ihm das Buch"); the imperative only changes the
   verb's form, not which case each object takes. mich would wrongly mean
   "give ME" as the thing being given.
2. "Komm jetzt." ✅ — correct du-imperative.
3. "Kommen herein." ❌ → "Kommen Sie herein!" — Sie-imperative needs the
   Sie pronoun stated (unlike du/ihr, where it's dropped) plus verb-first
   inversion. Learner explicitly flagged "herein" wasn't taught yet and
   asked it not be logged as vocabulary — respected, not added.
4. "Esst das Brot." ✅ — correct ihr-imperative.

**Result: du and ihr forms both solid; Sie-form missed the pronoun +
inversion on first exposure — single, expected first-contact gap, not a
pattern.** GRAMMAR.md's imperative row upgraded from INTRODUCED to
