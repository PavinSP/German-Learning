### euch/Zimmer exercise surfaced a real gap: im vs ins (two-way prepositions)

Prompt: "I see you all in the room." Answer given: "Ich sehe euch **ins**
Zimmer." — self-flagged as uncertain, offered "in das Zimmer" as a backup.

**Correct: "Ich sehe euch im Zimmer."** "in" is a TWO-WAY preposition: accusative
(ins = in+das) for motion INTO a place, dative (im = in+dem) for static
LOCATION. "I see you in the room" is location, not motion, so it needs im.
Two-way prepositions have never been formally taught — this is a natural next
topic surfacing early, not a gap in what was already covered. Logged to
ERROR_LOG.md ("ins used for location instead of motion").

**Learner asked (Q12, ANSWERS.md): why "in dem Zimmer" and not "in das
Zimmer"?** Answered in full: location (no movement) takes dative with two-way
prepositions like "in" — Zimmer is a das-word, dative gives "dem" → in dem
Zimmer → contracted im Zimmer. Movement INTO a place = accusative (ins Zimmer).
Already there/staying = dative (im Zimmer).

**Immediately applied correctly, unprompted:** "Mein Vater ist im Raum" — both
**im** (dative location, correct) and **der Raum** (new word, correctly used)
produced without being taught, right after the rule was explained. Raum added
to VOCABULARY.md.
