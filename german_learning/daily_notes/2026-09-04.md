## Lesson 7 — Dative case (introduction)

Learner chose dative case. Dative marks the indirect object (to/for whom).
Article changes: der/das-words → dem (they merge!), die-words → der, ein → einem,
eine → einer. Introduced with geben (gebe/gibst/gibt/geben/gebt/geben — stem
change like essen). Sentences with giving/showing/telling verbs often carry BOTH
a dative (person) and accusative (thing) object at once.

### Exercise set 1 (dative articles) — 4/4 clean
1. "Ich gebe dem Mann ein Buch." ✅
2. "Sie gibt der Frau eine Katze." ✅ (der Frau — die-word dative)
3. "Wir geben dem Kind Wasser." ✅ (dem Kind — das-word dative, correctly merged with der-word pattern)
4. "einer Katze." ✅ (eine → einer, dative)

Correctly produced "dem" for both der-words and das-words (the merge) and
"der/einer" for die-words, on the first attempt — no overgeneralization errors,
unlike the accusative introduction which needed a correction round.
