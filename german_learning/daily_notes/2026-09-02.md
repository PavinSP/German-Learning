## Re-teaching (slower, explicit this time)

- **Verb-second, restated plainly:** [Position 1: anything] — [Position 2: VERB] —
  [Position 3: subject, if not already position 1] — [rest]. Whatever leads the
  sentence "uses" position 1; the verb always claims position 2.
- **schlafen, full conjugation restated:** schlafe/schläfst/schläft/schlafen/
  schlaft/schlafen — schläft is already complete, nothing added.
- **mein/meine test:** always ask "der or die?" first — der Vater→mein,
  die Mutter→meine, every time, no shortcuts.

## Lesson 6, Part 2 — müssen & möchten (extending modal verbs)

müssen: muss/musst/muss/müssen/müsst/müssen. möchten: möchte/möchtest/möchte/
möchten/möchtet/möchten. Same pattern as können — modal in position 2, other verb
infinitive at the end.

### Exercise set — results (3/4 clean)
1. "Ich muss schlafen." ✅
2. "Möchtest du einen Äpfel essen?" ❌ → "...einen Apfel essen?" — used the plural
   spelling (Äpfel) for a singular noun; accusative ending (einen) was correct.
3. "Mein Vater muss morgen arbeiten." ✅ — verb-second held again, reinforcing
   yesterday's fix.
4. "Wir möchten den Hund sehen." ✅

Learner asked (DOUBTS.md): which verbs take accusative objects, and when to use
einen. Answered in full — accusative applies to the object of ANY action verb
(haben, sehen, essen, trinken, etc.); sein is the key exception since it doesn't
act on anything, just equates two things. Filed to ANSWERS.md as Q6.

### Fix-it retry
"Er möchte einen Apfel essen." ✅ — clean, correct conjugation (möchte for er) too.
